==================
tag.txt :: Empty start tag
==================
<>
---
(text
	(tag_start)
)


==================
tag.txt :: Empty end tag
==================
</>
---
(text
	(tag_end)
)


==================
tag.txt :: Incomplete start tag
==================
<
---
(text
	(ERROR)
)


==================
tag.txt :: Incomplete end tag
==================
</
---
(text
	(ERROR)
)
